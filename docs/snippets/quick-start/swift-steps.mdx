<Step title="Build the local Swift artifact">
From a Stark checkout:
```sh
cargo tools install swift
cargo tools build swift --targets macos
```
The package requires the local `stark.xcframework`; Stark has no published Swift binary.
</Step>
<Step title="Add the local package">
Add the Stark checkout as a local package in Xcode, then depend on the `Stark` product.
</Step>
