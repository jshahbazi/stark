<Step title="Build the local Python binding">
From a Stark checkout:
```sh
cargo tools install python
cargo tools build python
```
Stark has no published PyPI package. The local wheel is installed into the binding's `.venv`.
</Step>
<Step title="Run the example">
```sh
cargo tools example python chat
```
