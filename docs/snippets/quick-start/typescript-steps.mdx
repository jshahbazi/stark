<Step title="Build the local TypeScript binding">
From a Stark checkout:
```sh
cargo tools install typescript
cargo tools build typescript
```
The local package uses `@jshahbazi/stark`. Stark has no published npm or JSR package.
</Step>
<Step title="Run the example">
```sh
cargo tools example typescript chat
```
</Step>
