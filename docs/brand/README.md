# Stark visual identity

The cat-and-wordmark JPEG was supplied by the project owner as `stark-engine.jpg` for this presentation work. The repository and website use the original image without altering its pixels. Its SHA-256 is recorded in [provenance.json](provenance.json).

The visual direction uses warm paper, charcoal and gold. The README uses GitHub-supported Markdown/HTML; the site adds editorial typography, fine rules and a framed logo treatment. The brand image is decorative identity, while the product copy and measurements remain readable text.

| Token | Value | Use |
| --- | --- | --- |
| Paper | `#f3f2eb` | Main background |
| Charcoal | `#171b19` | Text and dark sections |
| Gold | `#efcc76` | Measured values and dark-surface links |
| Muted ink | `#63675f` | Secondary copy on paper |

The original upstream images and licensing/provenance assets remain available in their existing locations. The redesign changes the public entry points; it does not replace historical attribution.
