## Measured stopping point

On 4,096 input tokens at context 4,352 with zero reuse and exactly 256 outputs, the original target, vision and DSpark weights stayed resident with drafting off. The final sealed worker won all 16 matched pairs. Prefill medians were **683.34 tok/s greedy** and **685.31 tok/s seeded sampled**, about **1.78×** the prior worker, and the fastest request reached **808.32 tok/s**. Request wall time fell about **23%** at the paired medians. Useful decode rates moved from **33.26 to 31.38 tok/s** greedy and **32.09 to 30.31 tok/s** sampled, still inside the original decode ceilings. The precision change can alter generated text compared with the earlier Stark worker. [Worker results and host conditions](../../benchmarks/2026-11-21-inkling-mini-native-worker.md#source-aligned-m5-max-prefill)

The branch defaults to the source-aligned path on M5 Max for text prompts of at least 512 tokens at context up to 4,352 with drafting off. The source workspace and legacy prefill workspace measured 1,245 MiB and are covered by a 1,344 MiB reserve. Admission can choose the smaller incumbent workspace, and source setup can fall back. Short text, larger contexts, image input and draft-enabled requests use the earlier paths. The tested kill switch is `STARK_INKLING_SOURCE_PREFILL=0`. [Scope and fallback](../../INKLING_2_MINI_PLAN.md)

Restoring a 2,048-token prefix into a request with a changed 471-token suffix cut prefill from 4.139 s to 0.891 s and reproduced all 24 output IDs. Shortening prompts below the 2,048- and 4,096-row save boundaries rejected the snapshots and reproduced cold output. Cancellation cleared saved state. The final build reproduced the archived short and 4K slice hashes and passed vision, draft, streaming and tool round-trip controls. ## Lessons for the next run

- The complete packed graph removed a structural cost that launch-order changes and isolated kernel tuning barely moved. Attribute time on the current graph before reusing an old profile.
- Preserve exact native and source-aligned controls independently. A fast direct target replay, a matching connected slice and a matching stock-schedule generation seed each answer a different question.
- Compare one boundary at a time using the actual source indexing, reduction order and casts. Tiny differences in convolution or expert math can change routes and expand across the repeated visits.
- Bind prefix restore to the cold execution geometry. A valid snapshot must land on a complete bulk boundary that the incoming request actually reaches before its short suffix.
- Record timings from full worker requests separately from instrumented profiles and component estimates. Preserve the decoded-work count, input, context, sampling, output budget, residency and proof of zero reuse when comparing rates. [Performance playbook](../../PERFORMANCE_PLAYBOOK.md)
