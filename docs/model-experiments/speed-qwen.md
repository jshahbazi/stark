# Qwen dense and MoE speed history

Use the checkpoint and measurement boundary to choose a row. Prefill, useful decode, client wall time and conversion answer different questions. Each report identifies the measured workers and artifacts. For the hybrid Flash-Next architecture and its Lily packs, use the [Flash-Next history](speed-flash-next.md).
