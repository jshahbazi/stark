# Pinned Lily midpoint prefix capture

**20261117-FLASHSPEED-11–14 · November 17, 2026**

The generation worker enables midpoint capture by default for the admitted retained-vision `fabiogreter/Qwen3.8-Flash-Next-lily-q4-xl` artifact at revision `0f94842e3682b49acace4daeb4cf2e65a6f94f83` and artifact digest `18c7bcc1e97d1fefdd361472c2daa59d81d89fcd6f3a61983d995a032b44bfb4`. `STARK_LILY_PREFIX_MIDPOINT=0` is the release kill switch and restores the 4,096-token boundary grid. This adds the midpoint of each physical 4,096-token chunk as an eligible snapshot position. The worker keeps one snapshot. It uses fresh prefill when a midpoint restore would leave fewer than 17 suffix tokens; restored 64–127-row tails explicitly use the containing chunk's GDN schedule. Existing cache scope, token, context and MTP checks still apply.

The experiment build passed 12 full-model capture and restore comparisons with exact prompt, draft and target logits. All 18 fresh comparison pairs and all 94 paired native Pi requests matched emitted tokens and two-draft MTP work. In 16 Pi sessions, median paired turn time fell 15.34% and the midpoint arm won all eight matched session pairs. First-token time fell 55.32% at the median on the 50 native requests that reused an additional 2,048 tokens. The same four of eight sessions per arm passed the full grader. Fresh first-token medians increased by 2.63%, 5.51% and 4.98% at 8K, 12K and 32K. The owner accepted the 12K result when considering integration. A subsequent 12K profile measured 0.55 ms incremental allocation and zeroing over stock. The capture-bearing and untouched GPU passes varied across launch orders. The follow-up speed probe fused GDN/PLE midpoint window capture into their convolution kernels and admitted 17–127-token midpoint continuations while forcing the original 64-row GDN schedule. On the installed pinned artifact, 20 full-model capture/restore comparisons matched all 248,320 prompt logits, draft and target logits, emitted tokens and two-draft MTP work. The run covered 17, 64 and 127 suffix rows at 2K, a 17-token resume from the 10,240-token checkpoint, and the original 128, 293, 2,469, 2,048, 2,048 and 2,048-token cases. The test executable and private deterministic fixture had SHA-256 `d4e0ac1fc1eeed95747d644279317153d5111b4ff781076676058aafe6afde2e` and `455905e9f912b783cd0f6199f139f3c928a5fbb0c008158f139ba25396a4e53c`; the uncommitted patch SHA-256 at execution was `d5cef2756bbc231d4d65f5241a18f6196eba7a9c5c43a46afd1cc85305341704`.
