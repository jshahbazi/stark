## Hypothesis and change

- Problem: Stark admits Decider Flash v1.3 only, although the regular Decider v1.3 checkpoint uses the same protocol-v4, noncausal Qwen3.5 decision/readout contract.
- Baseline: Flash's pinned 4B `Qwen/Qwen3.5-4B` source uses tied embeddings.
- Candidate: Add the exact regular 27B `Qwen/Qwen3.8-27B` source as a separate Decision family. Its untied declaration has no generative `lm_head`; the prepared Decision-only graph retains the input embedding as an internal tied embedding because generation is never dispatched.
- Fixed acceptance gates: exact source identity, immutable file hashes, supported image protocol, complete 255-row readout, successful model-free planning, and preservation of Decider's Decision-only mode. A real model run must use a locked reference and private aggregate-only receipt before qualification.
