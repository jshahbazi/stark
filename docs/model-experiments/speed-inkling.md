# Inkling 2 Mini speed history

The Stark measurements use the original fixed-three-pass checkpoint on a 128 GiB M5 Max. Greedy and seeded temperature-1 rates appear in that order. Each row has its own comparator and timing boundary. The [native Metal retrospective](../archive/runs/2026-11-21-inkling-mini-native-retrospective.md) explains the sequence of changes and the numerical failures that guided it.
