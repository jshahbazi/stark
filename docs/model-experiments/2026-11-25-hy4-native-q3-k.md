### Text state restored by the pilot

Both full and sliding attention layers store MLA rows by absolute position in this artifact. The native rewind clamps completed pooled index groups at a boundary divisible by the four-position group size. The Rust worker retains the preceding scoped request's IDs through that boundary. The native draft path keeps the associated hidden history and truncates draft cache length and draft pooled-key count before replay. The final prefill chunk is executed again. These properties explain why the measured 3,072-token replay can reproduce the exact output without retaining decode rows. Scope, context and effective MTP depth enter the reuse key.

The native NextN path uses Q8_0 copies of the source BF16 draft matrices and output head, with source normalization and router precision retained. The target still verifies the greedy trajectory. Proposal and acceptance counts describe the selected draft execution policies of the two runtimes.
