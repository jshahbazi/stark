title: 'Stark'
---

Stark is an independent fork of the Uzu inference engine. The repository includes
the Rust engine, Metal and CPU backends, and inherited high-level language bindings.
See the [repository README](https://github.com/jshahbazi/stark) for the scoring scope,
supported build workflow, and current validation evidence.

The high-level examples in these pages were inherited from Uzu and now use the
Stark namespace. Python, TypeScript, and Swift packages have not been published for
this fork. Build the bindings from a local checkout before running the examples.

```sh
git clone https://github.com/jshahbazi/stark.git
cd stark
cargo tools install python
cargo tools build python
```

Replace `python` with `typescript` or `swift` for the corresponding local binding.
Swift requires a locally built `stark.xcframework`; the package never downloads an
upstream Uzu binary as a Stark artifact.

The inherited Mirai registry integration uses upstream provider endpoints and
model identifiers. Those identifiers remain unchanged for format compatibility.
The upstream [lalamo converter](https://github.com/trymirai/lalamo) and
[Uzu repository](https://github.com/trymirai/uzu) remain separate projects.

Report Stark issues in the
[Stark issue tracker](https://github.com/jshahbazi/stark/issues).
