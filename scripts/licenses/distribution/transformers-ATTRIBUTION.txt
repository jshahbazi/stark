Stark implements separate Rust/Metal kernels and F32 scratch/state storage for
these equations, with a software binary64 magnitude accumulator for Metal's
nonpositive F32 decay prefixes. It does not add a Transformers runtime
dependency. Pinned PyTorch/SLEEF arithmetic adaptations have separate notices
and source entries in manifest.json. The exact upstream Apache-2.0 license
file is preserved as transformers-LICENSE.
