01 / SETUP

Get started.

You’ll need an Apple silicon Mac with macOS 26.4 or newer. Model size and context length determine how much memory and storage you need.

  1. Install Stark. Download the Mac app, open the DMG and follow the installation steps.
  2. Choose a model. Open Stark from the menu bar, choose Beginner → Guided setup, then Find a model.
  3. Download and run it. Choose Download and set up, then follow the prompt to start the model.
  4. Start chatting. Choose Open chat, or connect one of the apps below. Advanced mode gives you the full catalog and import options.

02 / CONNECTIONS

Connect your apps.

With a model running in Chat mode, open Connections → Apps in Stark and choose Connect. Select Stark and your running model in the other app’s model picker.

OpenWork

Install OpenWork and open a workspace folder it can work in. If Stark asks, quit OpenWork completely and reopen it after connecting.

OpenWork setup guide ↗

OpenCode Desktop

Install the desktop app and connect it in Stark. Approve its engine when asked; updates or restarts can require a new approval.

OpenCode setup guide ↗

Other compatible apps

Copy the Base URL, API key and Model ID from Connections → Other apps into an OpenAI-compatible provider. Keep the key private. The API is local to your Mac.
